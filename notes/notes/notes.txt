XBox Controller:
Up,Down,Left,Right: D-Pad

NES button 'A'(Jump):XBox 'A' button
NES button 'B' (Attack):XBox 'X' button
NES button 'START' (Pause Menu): XBox 'Start' button
NES button 'SELECT': (Cast Spell)XBox 'Back' button

Any pad is picked up when plugged in (first free slot; a second pad is co-op P2).
Rebind everything in-game: Options -> EDIT CONTROLS (keyboard and controller).




Keyboard Controls:
RIGHT:'D' or 'ARROW RIGHT'
LEFT:'A' or 'ARROW LEFT'
UP:'W' or 'ARROW UP'
DOWN:'S' or 'ARROW DOWN'

NES button 'A'(Jump):'SPACE BAR'
NES button 'B' (Attack):'Ctrl'
NES button 'START' (Pause Menu): 'Enter'
NES button 'SELECT': (Cast Spell)'T'
Quick spell cycle: 'Q' next, 'E' previous

Audio:
'O':Fine adjust music and sound levels in options menu.
'M':Toggle music.
'N':Toggle sounds.

Jukebox / tracker (companion features):
'Insert': toggle the stream tracker window
'Home': toggle the NES jukebox      'Page Up' / 'Page Down': previous / next track
'End': assign the current track to this zone      'Delete': cycle the playlist view

Pause screen (randomizer saves):
'8': hint overlay    '9': key overlay    '0': show the game version

Window:
Fullscreen: 'F'  or  'Alt' + 'Enter'
Scale non-fullscreen Up: hold 'Ctrl', press 'G'
Scale non-fullscreen Down:hold 'Ctrl' + 'Shift', press 'G'

Stuck on the overworld (softlock):
Hold 'Ctrl' + 'Backspace' for a moment: returns to the last save point.

Quit App:
'Escape'  or  hold Xbox Right Trigger + Xbox Left Trigger + Xbox Back(Select) + Xbox Start

Twitch chat: Options -> TWITCH OPTIONS. Viewers type !commands; !help in chat
shows the card, ZALiA_Twitch_IRC_Setup\TWITCH_COMMANDS.txt has the full list.
