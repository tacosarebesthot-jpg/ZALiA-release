ZALiA — TWITCH SETUP

…

1. CONNECT YOUR TWITCH ACCOUNT

This opens Twitch's own login page in your normal browser. You sign in on twitch.tv, not here — this page never sees your password, and there is no field on it that asks for one. Twitch hands back a chat token, which is stored locally in %LOCALAPPDATA%\ZALiA\twitch_config.txt and never leaves your machine.

2. CHANNEL

VS CHAT MODE — CHAT IS TRYING TO KILL YOU

Every helpful command is refused while this is on — no !heal, !mp, !refill, !1up, !fairy, !invuln, !protect, !shield, !reflect or summoned allies. Chat can only hurt you. Turning it on also enables chat commands.

The chat-kill score is shown on the tracker, not here — this page is setup, and setup is not something you put on stream. Open TRACKER from the game's options menu and add it to OBS as a browser source.

3. CHAT EFFECTS

The master switch. With this off, chat can type commands all day and nothing happens. Turning VS CHAT on above switches it on for you.

4. WHAT CHAT CAN TYPE

Viewers type these in your chat. Everything in the HELPS YOU column is refused while VS CHAT MODE is on.

HELPS YOU

!heal !mp !refill !1up !fairy !invuln !protect !shield !reflect

HURTS YOU

!hurt !slow !flip !confuse !dark !spawn !swarm !freeze !steal

JUST CHAOS

!speed !party !cucco

APP ID (one-time, only if CONNECT does nothing)

The CONNECT button needs a Twitch application ID. If ZALiA shipped with one this is already filled in and you can ignore this box. Otherwise register a free app at dev.twitch.tv/console/apps, set its OAuth Redirect URL to exactly http://localhost:8777/twitch/callback, pick Application Integration, then paste the Client ID here.
